### 👨‍💻 Sobre Mim

Sou engenheiro de software e especialista em desenvolvimento **Full-Stack** com ênfase em **Aplicações com Inteligência Artificial Generativa**, **Agentes Autônomos** e sistemas corporativos de alta resiliência. 

Minha atuação é focada na intersecção entre engenharia de software de ponta e modelos de linguagem: desde a concepção de agentes autônomos com *Function Calling* e memória contextual persistente (*Knowledge Graphs* e busca vetorial) até o desenvolvimento de plataformas SaaS multi-tenant, pipelines resilientes de dados e automações fiscais e jurídicas.

* 🧠 **IA & Sistemas Cognitivos:** Desenvolvimento de agentes autônomos, orquestração de LLMs via OpenRouter/LiteLLM, RAG semântico com pgvector e Knowledge Graphs.
* 🚀 **SaaS & Full-Stack:** Construção de aplicações modernas de ponta a ponta com Python (FastAPI), Java (Spring Boot), React, TypeScript e Tailwind CSS.
* ⚡ **Automação & Engenharia de Dados:** Pipelines robustos de ETL, integração com bases públicas da Receita Federal e automações para ERPs corporativos (TOTVS Datasul).
